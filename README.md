# Ticketing Platform

High-demand ticketing platform: thousands of users compete for a limited number of seats,
and the system must never sell more tickets than exist.

Java portfolio project built as a set of Spring Boot microservices.

## Stack

Java 25, Gradle 9 (Kotlin DSL, version catalog, convention plugins), Spring Boot 4.0.x,
Spring Cloud 2025.1.x, PostgreSQL, Redis, Kafka.

## Build

```bash
./gradlew build
```

Work in progress: project skeleton.
